# Decisions

One file per decision, so the reasoning stays next to the code and an agent can find it. This folder starts empty:
no decisions are recorded yet. Add a file when a choice is worth remembering (a rule threshold, a data source, a
trade-off between two approaches), not for every change.

Name the file `YYYY-MM-DD-short-title.md` and copy the template below.

```markdown
# Short title of the decision

- Date: YYYY-MM-DD
- Status: proposed | accepted | superseded by <file>
- Decided by: name

## Context
What problem or question came up, and what was known at the time.

## Decision
What we chose, in one or two sentences.

## Why
The reasons, and the options that were set aside with why.

## Consequences
What this changes, what it costs, and when to revisit it.
```
