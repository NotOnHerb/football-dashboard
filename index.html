Individual offensive line ratings aren’t in this data: the file only lists linemen who drew a flag, so that table shows penalties and nothing about blocking quality. The numbers that grade blockers are ESPN’s pass and run block win rates (free on ESPN) and PFF grades (paid). Line unit stats here are shared with the QB and RBs behind them. An “edge” means the two units’ league ranks are 5 or more apart, which is a rough guide, not a prediction. Run defense allowed needs game-by-game data, so tackles for loss stands in for it. A lineman’s games count only weeks with a recorded stat. Edge rushers listed as OLB appear only with 2+ sacks. The schedule refreshes with the data.

A traded player’s stats count toward his most recent team, so team totals can be slightly off for teams with trades. Pass rate is approximate. Roster order is by 2026 usage, not an official depth chart. Pick a position to see its advanced stats. Rates for players with few touches swing wildly, so use the usage filter. The PPR, Half PPR and Standard buttons change the fantasy points per game column.
